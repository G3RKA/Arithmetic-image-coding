# Arithmetic image coding

Консольная программа на C++, которая кодирует BMP-изображения методом арифметического кодирования и декодирует их обратно. Сделана в рамках учебной практики 2 курса в ГУАП.

Метод описан в статье Witten, Neal, Cleary. *Arithmetic Coding for Data Compression* // Communications of the ACM, 30(6), 520–540, 1987.

## Что такое арифметическое кодирование

Арифметическое кодирование — метод энтропийного кодирования без потерь. Всё сообщение представляется одним числом из интервала [0, 1). Сначала интервал равен [0, 1). Для каждого символа он сужается до подынтервала, ширина которого пропорциональна вероятности символа. Частые символы сужают интервал слабо и поэтому занимают меньше бит, а дробное число бит на символ делает метод эффективнее кодов фиксированной длины и, как правило, кодирования Хаффмана.

## Как работает программа

**Кодирование**

1. Изображение `<имя>.bmp` загружается через `stb_image` в формате RGB, по 3 байта на пиксель.
2. Строится таблица частот для всех 256 значений байта (`FrequencyTable`). Модель статическая: частоты считаются один раз по всему изображению.
3. `ArithmeticEncoder` кодирует все байты изображения. Используется целочисленная реализация с 32-битными границами интервала: совпавшие старшие биты границ сразу выводятся в поток, а при сближении границ около середины интервала (underflow) отложенные биты накапливаются и выводятся позже.
4. Результат сохраняется в два файла:
   - `encoded_<имя>.bin` — закодированный битовый поток;
   - `encoded_<имя>.txt` — ширина и высота изображения и таблица частот (строки `значение частота`).

**Декодирование**

1. Из `encoded_<имя>.txt` загружаются размеры изображения и таблица частот.
2. `ArithmeticDecoder` читает `encoded_<имя>.bin` и восстанавливает `ширина × высота × 3` байт, на каждом шаге определяя символ по накопленным частотам.
3. Изображение записывается через `stb_image_write` в `decoded_<имя>.bmp`.

## Структура проекта

| Файл | Назначение |
|---|---|
| `Praktika.cpp` | точка входа: меню, загрузка и сохранение файлов |
| `FrequencyTable.h/.cpp` | таблица частот: построение, накопленные частоты, сохранение и загрузка |
| `ArithmeticEncoder.h/.cpp` | кодировщик |
| `ArithmeticDecoder.h/.cpp` | декодировщик |
| `stb_image.h`, `stb_image_write.h` | чтение и запись изображений, библиотеки [stb](https://github.com/nothings/stb) |

## Сборка и запуск

Внешних зависимостей нет: stb подключена исходниками. Проект создавался и собирается в Visual Studio (MSVC): создайте консольное приложение C++ и добавьте в него все `.cpp` и `.h` файлы репозитория.

Или из Developer Command Prompt for Visual Studio:

```bash
cl /EHsc /O2 /std:c++17 /utf-8 /Fe:arithmetic.exe Praktika.cpp FrequencyTable.cpp ArithmeticEncoder.cpp ArithmeticDecoder.cpp
```

Сборка проверена в Visual Studio 2026 (MSVC, x64). GCC/MinGW без доработок не подойдёт: в заголовках не подключён `<cstdint>`.

Использование:

1. Положите изображение `<имя>.bmp` в рабочую директорию программы.
2. Запустите программу, выберите пункт `1. Кодирование` и введите имя без расширения.
3. Для восстановления запустите снова, выберите `2. Декодирование` и введите то же имя. Файлы `encoded_<имя>.bin` и `encoded_<имя>.txt` должны лежать рядом.

## Особенности

- Кодирование без потерь: на тестовом изображении 500×500 декодированный BMP совпал с исходным побайтово, а закодированный поток занял около 22% от исходных 750 000 байт пиксельных данных.
- Таблица частот хранится отдельно в текстовом файле и нужна для декодирования.
- Размер закодированного потока зависит от распределения значений байтов: чем неравномернее распределение (например, большие однотонные области), тем он меньше.
- Изображение всегда обрабатывается как RGB; альфа-канал не сохраняется.
