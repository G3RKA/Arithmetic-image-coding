* stb_image
* stb_image_write.h
\
\
Source -> https://github.com/nothings/stb

# Input files must be in root directory

This algorithm encodes BMP images using the arithmetic coding method.

The method was originally described by Witten, Neal, and Cleary (1987) in Arithmetic Coding for Data Compression, Communications of the ACM, 30(6), 520–540.
